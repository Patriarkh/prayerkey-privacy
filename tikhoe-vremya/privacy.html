Политика конфиденциальности

Обновлено: 28 октября 2026 года.

Эта политика относится к приложению «Тихое время» для iOS (com.nickyrainq.tikhoevremya). Ответственный за приложение: Никита Райков (Ники). Контакт по вопросам данных: filyamon5@gmail.com.

Данные на устройстве

Настройки, ответы анкеты, молитвенные записи, заметки и прогресс сохраняются в локальной базе. Для использования приложения не требуется аккаунт. Резервное копирование устройства регулируется настройками iOS.

Персональная генерация молитв

При запуске генерации тема запроса и применимые ответы анкеты (например, возрастная группа, пол, конфессия, духовные цели, трудности, настроение и самооценка отношений с Богом) передаются по HTTPS через сервер приложения в API DeepSeek для подготовки текста. Свободный текст может содержать личные и чувствительные сведения. Не указывай имена других людей, контакты, медицинские сведения и другую информацию, которой не хочешь делиться с внешним сервисом. Можно пользоваться чтением Библии и локальными записями без генерации.

Сервер работает на инфраструктуре Cloudflare. Код сервера не сохраняет тексты молитв в базе, но это не означает отсутствия обработки или технических журналов у поставщиков инфраструктуры и API. Условия хранения и обработки на стороне DeepSeek требуют отдельной проверки для API; отсутствие хранения и использования для обучения мы не обещаем. Сервисы могут обрабатывать данные за пределами страны пользователя.

Защита сервера

Cloudflare получает IP-адрес при обращении. Для ограничения злоупотреблений сервер хранит почасовой счётчик запросов, привязанный к IP-адресу, до двух часов и общий дневной счётчик до суток. Эти данные нужны для работоспособности сервиса.

Разрешения iOS

Ограничение приложений использует Family Controls / Screen Time с разрешения пользователя. Уведомления требуют системного разрешения. Если используется запись голоса, доступ к микрофону запрашивается отдельно. Разрешения можно отозвать в настройках iOS.

Реклама, платежи и внешние ссылки

Приложение не содержит подписок и рекламного отслеживания. Добровольный перевод автору совершается вне приложения; платёжные сервисы обрабатывают данные по собственным правилам. Социальные сети и электронная почта открываются во внешних сервисах. Если ты пишешь автору, он получает адрес отправителя и содержание сообщения для ответа.

Управление данными

Локальные записи можно удалить на устройстве. Удаление приложения удаляет его локальные данные; резервные копии iOS управляются отдельно. По вопросам обработки переданных данных и запросам об удалении напиши автору. Возможности удаления на стороне сторонних сервисов зависят от их правил и применимого законодательства.

Изменения политики

При изменении обработки данных текст будет обновлён на этой странице.
